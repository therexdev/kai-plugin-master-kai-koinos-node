This is an independently owned KAI Foundation native plugin. Service code, assets, dependency bundles and persistent feature state belong here. The renderer remains sandboxed and uses window.kai.call. The native service is explicitly full-trust Electron code; never describe native.execute as a sandbox or promise native-code isolation from same-user files. Use the documented Foundation API v1 for shared services; do not import Core internals or another plugin's private files. This plugin owns its own encrypted Node wallet; do not read, replace or migrate Core/legacy wallets automatically. The user-authorized node migration may stop a verified legacy stack and transfer its chain-state files after explicit native review, with durable resume guards; it must not transfer wallet/producer keys or funds. Preserve unreadable wallet/funding journals and never silently overwrite them. Financial actions keep password proof, native review, exact payload/identity checks and operation cancellation. Never commit publisher private keys. Bundle locked dependencies at author build time; no client npm/postinstall. Run npm test and package verification before publishing a signed immutable release.
