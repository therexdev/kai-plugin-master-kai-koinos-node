# Master KAI Koinos Node 0.1.0

The complete Master Node workspace is now a separate KAI Core plugin, with the original dashboard and all nine sections, including **Distribution** and **Node API**.

Includes the current Distribution pause and Reset Stats behavior, saved recipients and pool allocation, Node API and optional history services, wallet/funding/external-signing controls, chain migration, automatic recovery and reward returns. The current Node plugin's wallet protections, styled reviews and Windows configuration repair are retained.

**Node settings → Migrate from Master Koinos AI Node** transfers the old Master chain with verified source ownership, progress, pause/resume and space-saving moves. Close the old Master app and tray process before confirming. Wallets, private production keys, KOIN and VHP are not transferred; mining remains off.

Requires **KAI Core 0.7.3 or later**. Installs independently from Koinos Node with its own data and wallet; no legacy or other-plugin data is adopted automatically. Distribution and the API start disabled. Public HTTPS exposure requires a separately configured tunnel.

Native installation requires full computer/application trust. Validation uses disposable and synthetic integration fixtures; no live node, funds, public tunnel or user wallet is changed during release testing.
